# Автоматизация Black Myth: Wukong Benchmark Tool

WukongBench — консольное приложение на C# (.NET 8), которое автоматически запускает два прохода Black Myth: Wukong Benchmark Tool: с настройками для оценки производительности CPU и GPU. После каждого прохода программа читает JSON с результатом и в конце сохраняет `benchmark_report.md` с характеристиками компьютера, метриками и настройками тестов.

## Запуск

Необходимы Windows, .NET 8 SDK, Steam и установленный Black Myth: Wukong Benchmark Tool.

Откройте терминал в каталоге с `WukongBench.csproj` и выполните:

```powershell
dotnet run
```

По умолчанию программа ищет бенчмарк в папке:

```text
C:\Program Files (x86)\Steam\steamapps\common\Black Myth Wukong Benchmark Tool
```

Если он установлен в другом месте, передайте путь первым аргументом:

```powershell
dotnet run -- "D:\SteamLibrary\steamapps\common\Black Myth Wukong Benchmark Tool"
```

Если автоматические нажатия не подходят для вашего окна, можно запускать тест вручную:

```powershell
dotnet run -- --manual-start
```

В этом режиме после запуска бенчмарка нужно вручную нажать «Нажмите любую кнопку для продолжения» и «Тест быстродействия» и подтвердить запуск.

## Результаты

Программа последовательно выполняет CPU- и GPU-тесты. После каждого прогона она ждёт новый файл с результатами в `%TEMP%\b1\BenchMarkHistory\Tool`, считывает содержащийся в нём JSON и закрывает бенчмарк. После двух успешных прогонов отчёт `benchmark_report.md` создаётся в каталоге запуска.

Также некоторые комментарии по ходу выполнения программы и краткие отчёты будут отображаться в консоли. Пример:

Результаты (из JSON самого бенчмарка):
- Средний FPS: 120, максимум: 144, минимум: 72, 5-й перцентиль: 111
- Средняя загрузка GPU: 95%, видеопамять: 2,7 ГБ
- Среднее время кадра: CPU 8,1 мс, GPU 6,9 мс (замеров: 17034)
- Потолок FPS по времени кадра: процессор 123, видеокарта 145; получено 120
- Вывод: упор в процессор (CPU-bound)

В отчёт входят характеристики компьютера, средний, минимальный и максимальный FPS, 5-й перцентиль, загрузка GPU, время кадра CPU/GPU и настройки каждого теста.

## Настройки бенчмарка

Настройки двух прогонов хранятся в `profiles/cpu.ini` и `profiles/gpu.ini`.


| Параметр | CPU-тест (`cpu.ini`) | GPU-тест (`gpu.ini`) |
|---|---|---|
| **Экран** | | |
| Разрешение | 1280 × 720 | 1920 × 1080 |
| Порог частоты кадров | Выключена | Выключена |
| Вертикальная синхронизация | Выключена | Выключена |
| Размытие при движении | Очень заметные | Очень заметные |
| **Рекомендуемые настройки** | | |
| Степень избыточной выборки сглаживания | Около 33% | 100% |
| Избыточная выборка сглаживания | DLSS | TSR |
| Генерация кадров | Выключена | Выключена |
| Полная трассировка лучей | Выключена | Включена, уровень 3 |
| Качество графики (Расшир. настройки граф.) | Минимальное | Высокое |

Расширенные настройки графики:
* Детализация объектов вдали
* Дальность прорисовки объектов
* Качество сглаживания
* Качество постобработки
* Качество теней
* Качество текстур
* Качество визуальных эффектов
* Качество волос
* Общее качество освещения
* Качество отражений

CPU-профиль использует самые низкие настройки графики, разрешения, трассировки лучей, чтобы максимально убрать нагрузку с видеокарты, а GPU-профиль использует самое высокое разрешение, качество графики и трассировку лучей. 

Профили подбирались опытным путём на одной машине: на другом компьютере CPU-тест может показывать смешанную нагрузку, а результаты будут зависеть от оборудования и режима питания.

Профили — это полные файлы настроек, а не отдельные параметры. Чтобы изменить их, задайте нужные настройки в Benchmark Tool, закройте его и сохраните полученный `GameUserSettings.ini` как `profiles/cpu.ini` или `profiles/gpu.ini`. Перед запуском программа сохраняет пользовательский `GameUserSettings.ini`, а после завершения возвращает исходный файл.
