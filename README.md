# WukongBench — автоматический бенчмарк Black Myth: Wukong

Инструмент на C# (.NET 8) для локального автоматизированного запуска **Black Myth: Wukong Benchmark Tool** из Steam.

Программа выполняет **два прохода** с разными наборами настроек:

1. **CPU-тест** — настройки подобраны так, чтобы основная нагрузка приходилась на процессор, а влияние видеокарты было минимальным.
2. **GPU-тест** — настройки на максимум, чтобы максимально нагрузить видеокарту.

После каждого прохода читается JSON-результат самого бенчмарка. В конце формируется отчёт `benchmark_report.md` с характеристиками ПК, метриками обоих тестов, применёнными настройками и выводом о том, во что упёрся тест (CPU / GPU / смешанная нагрузка).

## Минимальные требования

| Компонент | Требование |
|-----------|------------|
| ОС | **Windows 10/11** (x64) |
| Runtime | **.NET 8 SDK** ([скачать](https://dotnet.microsoft.com/download/dotnet/8.0)) |
| Steam | Установлен и запущен |
| Игра | **Black Myth: Wukong Benchmark Tool** (AppID `3132990`) установлен через Steam |
| Питание | Для ноутбуков — **от сети** (на батарее результаты занижены и нестабильны) |
| Разрешение | Рекомендуется 16:9 (клики в долях окна; при другом aspect ratio есть `--manual-start` / `--click`) |

Путь установки по умолчанию:
`C:\Program Files (x86)\Steam\steamapps\common\Black Myth Wukong Benchmark Tool`

## Запуск

Из папки с `WukongBench.csproj`:

```powershell
dotnet run
```

Сборка:

```powershell
dotnet build -c Release
```

Другой путь установки:

```powershell
dotnet run -- "D:\SteamLibrary\steamapps\common\Black Myth Wukong Benchmark Tool"
```

Основной сценарий выполняется **автоматически** без флагов: бэкап ini → CPU-профиль → запуск → ожидание JSON → GPU-профиль → отчёт → восстановление ini.

## Как это работает

1. Сохраняет текущий `GameUserSettings.ini` в резервную копию.
2. Подставляет профиль `profiles/cpu.ini` (целиком, включая блок `[ScalabilityGroups]`).
3. Запускает бенчмарк через Steam (`steam://rungameid/3132990`).
4. Автоматически проходит заставку, выбирает «Тест быстродействия» и подтверждает запуск.
5. **Не** ждёт фиксированное время: следит за папкой `%TEMP%\b1\BenchMarkHistory\Tool` и ждёт появления нового файла с результатом (таймаут 15 мин — только защита от зависания).
6. Парсит JSON, закрывает игру, повторяет шаги с `profiles/gpu.ini`.
7. Восстанавливает исходный ini (в том числе при ошибке или Ctrl+C) и пишет `benchmark_report.md`.

### Клики по меню

Координаты заданы **в долях ширины/высоты окна** (`GetWindowRect`), поэтому **не зависят от разрешения экрана**. Для устойчивости:

- несколько кандидатных точек для пункта меню и кнопки «Подтвердить»;
- дублирование нажатиями **Enter** и **Space**;
- повторное выведение окна на передний план перед каждым действием.

Если меню выглядит иначе (другой aspect ratio, масштаб UI), используйте:

```powershell
dotnet run -- --manual-start          # клики вручную
dotnet run -- --click 0.50:0.55       # своя точка в долях окна
dotnet run -- --delay 40              # дольше ждать заставку (сек)
```

### Определение узкого места

Счётчик загрузки CPU в JSON бенчмарка не работает (всегда 1). Программа сравнивает среднее время кадра `CPUFrameTime` и `GPUFrameTime`:

- GPU > CPU на >15% → упор в видеокарту;
- CPU > GPU на >15% → упор в процессор;
- иначе — смешанная нагрузка.

## Профили настроек

| Профиль | Разрешение | Рендер | Графика | RT | Frame Gen |
|---------|------------|--------|---------|----|-----------|
| `profiles/cpu.ini` | 1280×720 | ~33% | всё на минимуме | выкл | выкл |
| `profiles/gpu.ini` | 1920×1080 | 100% | всё на максимуме | Ultra | выкл |

Профили сняты с лаунчера бенчмарка. Менять отдельные строки в `UISettingData` недостаточно — часть параметров берётся из `[ScalabilityGroups]`.

Не меняйте ini-файлы, если хотите сохранить подобранный баланс. На другой конфигурации CPU/GPU соотношение может отличаться.

## Аргументы командной строки

```
WukongBench [папка_установки]
            [--manual-start]
            [--out report.md]
            [--profiles папка_с_cpu.ini_и_gpu.ini]
            [--mode "режим мощности"]
            [--click X:Y]
            [--delay секунд]
WukongBench --report result.json   # только отчёт по готовому JSON
```

| Флаг | Назначение |
|------|------------|
| `--manual-start` | Не кликать по меню — ждать ручного запуска теста |
| `--out path` | Куда сохранить отчёт (по умолчанию `benchmark_report.md`) |
| `--profiles dir` | Папка с `cpu.ini` и `gpu.ini` |
| `--mode "..."` | Произвольная строка (например «Turbo, от сети») — попадёт в отчёт |
| `--click X:Y` | Доли окна 0..1 для пункта «Тест быстродействия» |
| `--delay N` | Секунд ожидания до заставки (по умолчанию 25) |
| `--report file` | Построить отчёт из уже существующего JSON без запуска игры |

```
│   ├── cpu.ini
│   └── gpu.ini

```

## Ограничения

- Профили подобраны на одной машине (Ryzen 7 5800H + RTX 3060 Laptop). На другом железе баланс CPU/GPU может сдвинуться.
- Режим производительности ноутбука (Armoury Crate и т.п.) Windows не отдаёт — укажите вручную через `--mode`.
- Клики устойчивы к разрешению экрана, но при сильно отличном UI/aspect ratio может понадобиться `--manual-start` или `--click`.
- Соответствие полей JSON настройкам в ini установлено эмпирически (у инструмента нет официальной документации на формат).
